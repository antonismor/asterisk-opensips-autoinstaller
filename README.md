# Asterisk & OpenSIPS Auto Installer

An interactive Bash-based installation toolkit for deploying Asterisk, OpenSIPS, OpenSIPS Control Panel, and additional VoIP-related packages.

The installer provides a simple menu-driven interface and allows you to choose between a clean progress-bar installation mode or full verbose output.

---

## Features

- Automated Asterisk installation
- Automated OpenSIPS installation
- OpenSIPS Control Panel installation
- Interactive menu-based installation
- Select which packages you want to install
- Progress Bar installation mode
- Verbose installation mode
- Automatic dependency installation
- Step-by-step installation process
- Designed to simplify VoIP server deployment

---

## Requirements

Before starting, make sure you have:

- A Linux server
- Root or `sudo` access
- An active Internet connection
- Bash shell
- Git, if you are cloning the repository
